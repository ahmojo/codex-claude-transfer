Health check

Confirms cct can see your local sessions for the selected tool, and which optional tools are installed.

Your sessions

Sessions discovered on this machine for the selected tool.

Search sessions

Full-text search across your conversation text. Find a past session, then resume, tag, or export it.

Stats

A summary of your sessions for the selected tool: totals, busiest projects, recent activity.

Scan for secrets

Heuristically flags likely API keys and tokens in your sessions, so you can review before sharing. Read-only — nothing is changed.

Export a bundle

Package sessions into one .codexbundle file to move to another machine.

Project folder

Saves a pointer to your code (remote URL + commit id) inside the bundle so the other machine knows what to check out. Reads git locally — uploads nothing.

Network upload. Runs git push of the current branch to your own git remote, so the commit recorded in the bundle is actually fetchable on the other machine. Pushes code only — never your sessions, and never to any cct server. Needs a single project with a remote.

Replaces inline screenshots/photos (stored as base64) with a small placeholder. Lossy — the pictures are dropped — but the conversation text is kept. Handy for image-heavy sessions.

By default, export refuses to write a bundle that contains a likely API key or token. Tick this to mask them, or you'll be offered "Export anyway" if any are found.

Encrypt the bundle (optional, needs age)

Passphrase encryption is terminal-only (cct export --passphrase); the browser uses recipient keys, which need no prompt.

Inspect a bundle

Read a .codexbundle without extracting anything.

Import a bundle

Bring sessions from a bundle into the matching agent's home on this machine. Always previewed first.

Options

Groups the bundle's sessions under the folder cct app was launched in, so you don't have to look up the original path. Only for a single-project bundle.

When a session already exists here but differs

Network download. Runs git clone of the remote recorded in this bundle into the folder above and checks out the recorded commit. Fetches code only from that remote; your sessions are imported separately (above). Leave blank to skip.
