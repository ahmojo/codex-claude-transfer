English

Проверка готовности

Проверяет доступность локальных чатов выбранной программы и дополнительных утилит.

Ваши чаты

Чаты выбранной программы, найденные на этом компьютере.

Поиск по чатам

Поиск по тексту переписки. Найдите чат, чтобы продолжить его, добавить метку или экспортировать.

Статистика

Сводка по чатам выбранной программы: количество, проекты и недавняя активность.

Поиск секретов

Ищет в чатах возможные ключи API и токены. Перед передачей проверьте результаты. Сканирование ничего не меняет.

Экспорт архива

Сохраните чаты в один файл .codexbundle для переноса на другой компьютер.

Папка проекта

Записывает в архив ссылку на код (адрес репозитория и ID коммита), чтобы другой компьютер знал, какую версию получить. Читает git локально, ничего не загружает в сеть.

Отправка в сеть. Команда git push отправит текущую ветку в ваш удалённый репозиторий, чтобы другой компьютер мог получить указанный коммит. Отправляется только код, без чатов. Нужен один проект с удалённым репозиторием.

Заменяет встроенные снимки экрана и фотографии короткими пометками. Изображения будут утрачены, текст переписки сохранится.

По умолчанию экспорт блокируется при обнаружении возможного ключа API или токена. Включите маскирование либо, если секреты найдутся, выберите «Экспортировать всё равно».

Зашифровать архив (необязательно, нужна утилита age)

Шифрование паролем доступно только в терминале (cct export --passphrase); в браузере используются ключи получателей.

Просмотр архива

Просмотр содержимого .codexbundle без извлечения файлов.

Импорт архива

Добавляет чаты из архива в папку соответствующей программы на этом компьютере. Перед импортом показывается предварительный результат.

Параметры

Привязывает чаты к папке, из которой запущена команда cct app. Исходный путь искать не нужно. Доступно для архива одного проекта.

Если чат уже существует, но отличается

Использует сервер приложений Codex. Если он недоступен или несовместим, импортированные файлы сохранятся, а cct покажет, как безопасно перезапустить или продолжить чат.

Загрузка из сети. Команда git clone скачает код из репозитория, указанного в архиве, в выбранную папку и переключится на записанный коммит. Скачивается только код; чаты импортируются отдельно. Оставьте поле пустым, чтобы пропустить.
